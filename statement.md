# Project Statement

## Problem Statement

A small library needs a simple way to keep track of books and whether they are available or borrowed.

## Proposed Solution

Library Book Manager is a command-line Python application that stores book records, supports searching, and changes the status of a book when it is borrowed or returned.

## Target Users

Students, small classroom libraries, and beginner-level library management use cases.

## Main Modules

1. Book model
2. Library management
3. Search and status operations
4. Library reporting
5. Input validation

## Scope

The project is a local command-line application. It does not include online accounts, payment systems, or AI features.
